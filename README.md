# S&Y Tree Services - Landing Page v1.0

Professional tree service company landing page for the Minneapolis-St. Paul metro area.

## Tech Stack

- **HTML5** - Semantic, accessible markup
- **CSS3** - Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript ES6** - Modular IIFE architecture
- **No frameworks, no dependencies**

## Features

- Fully responsive (mobile-first)
- Bilingual (EN/ES) with language toggle
- Dark mode support
- Scroll reveal animations
- Image gallery with lightbox + filtering
- Before & After slider
- FAQ accordion
- Contact form with validation + file upload
- Cookie consent banner
- Loading screen
- Back to top button
- Floating WhatsApp/Call buttons
- Sticky CTA (mobile)
- SEO optimized (meta, OG, JSON-LD Schema)
- WCAG 2.2 accessibility
